# 高考志愿数据查询系统

这是一个可部署到 GitHub Pages 的静态网站原型，按云南 2026 新高考口径设计，目标是承载“全国高校在云南招生”的查询库。

## 当前能力

- 云南 3+1+2 的 12 种选科组合展示
- 按首选科目、选科组合、分数、位次、专业方向、院校层次筛选
- 自动排除不满足选科要求的专业组
- 按位次粗分“冲、稳、保”
- 内置数据源草稿库和正式导入字段模板
- 增加政策匹配检查：3+1+2、物理/历史分列、院校专业组、昆明考生省级口径
- 位次字段要求使用官方全省位次；分数只做辅助展示，不用分数估算推荐结果

## 数据完整性说明

当前网页里的院校专业组是演示库，只用于验证查询、选科匹配和手机展示逻辑，不代表真实完整志愿推荐。正式使用前必须导入全国高校在云南的当年招生计划、官方一分一段表、历年投档线和高校招生章程。

## 重要口径

- 云南从 2025 年起实行“3+1+2”新高考，不再按传统文理科填报。
- 普通类按物理科目组合、历史科目组合分别划线。
- 志愿以“院校专业组”为核心单位。
- 昆明考生不使用单独的“昆明招生计划”，而是使用云南省统一招生计划、云南省一分一段位次和云南省投档规则。
- 准确推荐必须使用官方全省位次。高考总分不能跨年份直接比较，也不能替代一分一段位次。
- “一本、二本”在新高考本科批合并后不适合作为唯一筛选条件，应改用院校层次、专业实力、历年最低位次和招生计划。

## 数据来源优先级

1. 云南省招生考试院：https://www.ynzs.cn
2. 云南高考考生服务平台：https://gk.ynzs.cn
3. 阳光高考云南政策库：https://gaokao.chsi.com.cn/gkxx/zc/ss?regionId=086530000
4. 阳光高考院校库：https://gaokao.chsi.com.cn/sch/
5. 教育部本科专业目录：https://www.moe.gov.cn
6. 2026 招生考试报/招生计划专刊，需要 OCR 或人工录入
7. 各高校本科招生网和招生章程
8. 第三方聚合平台只做缺漏发现和交叉核验，不作为唯一依据

## 文件说明

- `index.html`：网站页面
- `styles.css`：界面样式
- `app.js`：查询、筛选、风险分类逻辑
- `data/sample-data.js`：演示数据
- `data/import-template.csv`：正式数据导入字段模板

## 本地预览

在本目录启动静态服务，然后打开浏览器访问本地地址。

```bash
python3 -m http.server 4173
```

## 发布到 GitHub Pages

1. 在 GitHub 新建仓库，例如 `gaokao-volunteer-site`。
2. 将本目录文件提交并推送到仓库。
3. 在仓库 Settings -> Pages 中选择 `Deploy from a branch`。
4. 分支选择 `main`，目录选择 `/root`。
5. 等待 GitHub 生成访问地址。
